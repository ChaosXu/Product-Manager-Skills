# SaaS-Economics-Efficiency-Metrics 术语表

## 术语表

| 术语 | 中文 | 解释 | 引用 |
|------|------|------|------|
| Unit Economics | 单元经济学 | 客户层面的盈利能力（毛利率、CAC、LTV、回收期、贡献利润） | skills/saas-economics-efficiency-metrics/SKILL.md |
| Capital Efficiency | 资本效率 | 你用现金增长的效率（消耗率、跑道、OpEx、净收入、营运资本） | skills/saas-economics-efficiency-metrics/SKILL.md |
| Efficiency Ratios | 效率比率 | 综合指标（40法则、魔法数字、运营杠杆） | skills/saas-economics-efficiency-metrics/SKILL.md |
| Gross Margin | 毛利率 | (收入-销货成本)/收入×100——SaaS 70-85%为佳 | skills/saas-economics-efficiency-metrics/SKILL.md |
| COGS | 销货成本 | 托管、基础设施、支付处理、入门成本 | skills/saas-economics-efficiency-metrics/SKILL.md |
| CAC | 客户获取成本 | 总销售与营销支出/获取的新客户数 | skills/saas-economics-efficiency-metrics/SKILL.md |
| LTV (Lifetime Value) | 客户终身价值 | ARPU×毛利率%/流失率 | skills/saas-economics-efficiency-metrics/SKILL.md |
| LTV:CAC Ratio | 客户终身价值与获取成本比 | LTV/CAC——3:1健康，<1:1不可持续，>5:1投资不足 | skills/saas-economics-efficiency-metrics/SKILL.md |
| Payback Period | 投资回收期 | CAC/(月度ARPU×毛利率%)——<12个月为佳 | skills/saas-economics-efficiency-metrics/SKILL.md |
| Contribution Margin | 贡献利润率 | (收入-所有可变成本)/收入×100——SaaS 60-80%为佳 | skills/saas-economics-efficiency-metrics/SKILL.md |
| Gross Margin Payback | 毛利率回收期 | 使用实际利润而非收入的回收计算 | skills/saas-economics-efficiency-metrics/SKILL.md |
| CAC Payback by Channel | 按渠道的CAC回收期 | 比较各获取渠道的回收情况 | skills/saas-economics-efficiency-metrics/SKILL.md |
| Burn Rate | 消耗率 | 毛额：每月现金支出；净额：每月现金支出-收入 | skills/saas-economics-efficiency-metrics/SKILL.md |
| Runway | 资金跑道 | 现金余额/每月净消耗——12+个月为佳 | skills/saas-economics-efficiency-metrics/SKILL.md |
| OpEx | 运营支出 | 运营费用：销售与营销+研发+管理 | skills/saas-economics-efficiency-metrics/SKILL.md |
| Net Income/Profit Margin | 净收入/利润率 | 收入-所有费用 | skills/saas-economics-efficiency-metrics/SKILL.md |
| Working Capital Impact | 营运资本影响 | 收入确认和现金收取之间的现金时间差 | skills/saas-economics-efficiency-metrics/SKILL.md |
| Rule of 40 | 40法则 | 收入增长百分比+利润百分比——>40健康 | skills/saas-economics-efficiency-metrics/SKILL.md |
| Magic Number | 魔法数字 | (本期收入-上期收入)×4/上期销售与营销费用——>0.75高效 | skills/saas-economics-efficiency-metrics/SKILL.md |
| Operating Leverage | 运营杠杆 | 收入增长vs运营支出增长——收入增长快时为正 | skills/saas-economics-efficiency-metrics/SKILL.md |
| Cash Trap | 现金陷阱 | LTV:CAC出色但回收期极差的组合（如48个月回收的6:1比率） | skills/saas-economics-efficiency-metrics/SKILL.md |
| Metric | 指标 | 用于衡量业务或产品表现的量化数据 | skills/saas-economics-efficiency-metrics/SKILL.md |
| Churn Rate | 流失率 | 取消的客户百分比 | skills/saas-economics-efficiency-metrics/SKILL.md |
