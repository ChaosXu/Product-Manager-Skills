| 术语 | 中文 | 解释 | 引用 |
|------|------|------|------|
| MRR/ARR | 月度/年经常性收入 | 可预测的定期 recurring revenue | skills/finance-metrics-quickref/SKILL.md |
| NRR | 净收入留存率 | 收入留存加扩展的综合指标 | skills/finance-metrics-quickref/SKILL.md |
| CAC | 客户获取成本 | 获取一个新客户的总成本 | skills/finance-metrics-quickref/SKILL.md |
| LTV | 客户终身价值 | 一个客户预计带来的总收益 | skills/finance-metrics-quickref/SKILL.md |
| LTV:CAC Ratio | 客户终身价值与获取成本比 | 获取支出的效率（应为3:1+） | skills/finance-metrics-quickref/SKILL.md |
| Payback Period | 投资回收期 | 从客户收入中回收CAC的月份 | skills/finance-metrics-quickref/SKILL.md |
| Gross Margin | 毛利率 | (收入-销货成本)/收入×100 | skills/finance-metrics-quickref/SKILL.md |
| Contribution Margin | 贡献利润率 | (收入-所有可变成本)/收入×100 | skills/finance-metrics-quickref/SKILL.md |
| Burn Rate | 消耗率 | 每月消耗的现金 | skills/finance-metrics-quickref/SKILL.md |
| Runway | 资金跑道 | 现金耗尽前的月份数 | skills/finance-metrics-quickref/SKILL.md |
| OpEx | 运营支出 | 运营费用：销售与营销+研发+管理 | skills/finance-metrics-quickref/SKILL.md |
| Net Income | 净收入 | 收入-所有费用 | skills/finance-metrics-quickref/SKILL.md |
| Rule of 40 | 40法则 | 收入增长百分比+利润百分比（应超过40%） | skills/finance-metrics-quickref/SKILL.md |
| Magic Number | 魔法数字 | (本季度收入-上季度收入)×4/上季度销售与营销费用 | skills/finance-metrics-quickref/SKILL.md |
| Operating Leverage | 运营杠杆 | 收入增长vs运营支出增长 | skills/finance-metrics-quickref/SKILL.md |
| Quick Ratio | 快速比率 | (新MRR+扩展MRR)/(流失MRR+收缩MRR) | skills/finance-metrics-quickref/SKILL.md |
| Expansion Revenue | 扩展收入 | 追加销售+交叉销售+使用增长 | skills/finance-metrics-quickref/SKILL.md |
| ARPU | 每用户平均收入 | 总收入/总用户数 | skills/finance-metrics-quickref/SKILL.md |
| ARPA | 每账户平均收入 | 月度经常性收入/活跃账户数 | skills/finance-metrics-quickref/SKILL.md |
| ACV | 年合同价值 | 每合同的年度经常性收入 | skills/finance-metrics-quickref/SKILL.md |
| Churn Rate | 流失率 | 取消的客户百分比 | skills/finance-metrics-quickref/SKILL.md |
| Cohort Analysis | 队列分析 | 按加入日期对客户分组并追踪行为 | skills/finance-metrics-quickref/SKILL.md |
| Revenue Concentration | 收入集中度 | 前N客户/总收入的占比 | skills/finance-metrics-quickref/SKILL.md |
| Revenue Mix | 收入组合 | 产品/细分收入/总收入 | skills/finance-metrics-quickref/SKILL.md |
| Incrementality | 增量收入 | 由行动产生的收入-基准值 | skills/finance-metrics-quickref/SKILL.md |
| Working Capital | 营运资本 | 收入和收款之间的现金时间差 | skills/finance-metrics-quickref/SKILL.md |
| Unit Economics | 单元经济学 | 每单位收入-每单位成本 | skills/finance-metrics-quickref/SKILL.md |
| Segment Payback | 细分回收期 | CAC/月度贡献（按细分） | skills/finance-metrics-quickref/SKILL.md |
| Gross Margin Payback | 毛利率回收期 | CAC/(月度ARPU×毛利率%) | skills/finance-metrics-quickref/SKILL.md |
| Metric | 指标 | 用于衡量业务或产品表现的量化数据 | skills/finance-metrics-quickref/SKILL.md |
