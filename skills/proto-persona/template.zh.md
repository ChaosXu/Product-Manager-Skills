# 原型人物角色模板

使用此模板来捕捉一个假设驱动的人物角色画像。

## 来源

改编自 `https://github.com/deanpeters/product-manager-prompts` 仓库中的 `prompts/proto-persona-profile.md`。

## 模板

```markdown
### 姓名
- [押头韵的名字]

### 生物特征与人口统计
- [年龄段]
- [地理位置]
- [社会状态]
- [在线状态]
- [休闲活动]
- [职业状态]

### 语录
- "[语录 1]"
- "[语录 2]"
- "[语录 3]"

### 痛点
- [痛点 1]
- [痛点 2]
- [痛点 3]

### 这个人试图完成什么？
- [行为或结果 1]
- [行为或结果 2]
- [行为或结果 3]

### 目标
- [目标 1]
- [目标 2]
- [目标 3]

### 态度与影响力
- **决策权限：** [是/否 + 背景]
- **决策影响者：** [谁影响这个人]
- **信念与态度：** [影响决策的信念/态度]
```
