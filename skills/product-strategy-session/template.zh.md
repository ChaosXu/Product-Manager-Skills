# 产品策略会议模板

使用此模板来捕获策略会议的输出。

## 模板

```markdown
# 产品策略会议总结

## 策略背景
- [公司目标 / OKR]
- [市场背景 / 竞争]

## 目标客户
- [主要人物角色]
- [关键 JTBD / 需求]

## 问题框架
- [问题陈述]
- [为什么是现在]

## 机会
- [顶级机会]

## 解决方案假设
- [Epic 假设]

## 优先级排序
- [使用的框架 + 最高优先级]

## 路线图 / 排序
- [现在 / 下一步 / Later 或季度]

## 成功指标
- [关键指标]

## 下一步
- [实验、发现、PRD、路线图规划]
```
