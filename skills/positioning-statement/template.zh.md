# 定位陈述模板

使用此模板制作 Geoffrey Moore 风格的定位陈述。

## 出处
改编自 `https://github.com/deanpeters/product-manager-prompts` repo 中的 `prompts/positioning-statement.md`。

## 模板
```markdown
## 定位陈述

### 价值主张

**For** [目标客户/人物画像]
- **that need** [未满足的需求]
- [产品或服务名称]
- **is a** [产品类别]
- **that** [聚焦成果的利益陈述]

### 差异化陈述

- **Unlike** [主要竞争对手或替代方案]
- [产品或服务名称]
- **provides** [聚焦成果的独特差异化]
```
