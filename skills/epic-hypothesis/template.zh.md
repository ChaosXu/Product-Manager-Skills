# Epic 假设模板

使用此模板将 epic 框架为可测试的假设，包含实验和验证措施。

## 来源

改编自 `https://github.com/deanpeters/product-manager-prompts` repo 中的 `prompts/backlog-epic-hypothesis.md`。

## 模板
```markdown
### If/Then 假设

**If we** [代表目标画像采取的动作或解决方案]
**for** [目标画像]
**Then we will** [desirable 的成果或待完成的工作]

### 微小的发现行为实验

**We will test our assumption by:**
- [实验 1]
- [实验 2]
- [根据需要添加更多]

### 验证措施

**We know our hypothesis is valid if within** [时间范围]
**we observe:**
- [可量化的可衡量成果]
- [可量化的定性成果]
- [根据需要添加更多]
```
