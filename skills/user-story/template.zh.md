# 用户故事模板

使用此模板编写具有 Gherkin 风格验收标准的单个用户故事。

## 出处

改编自 `prompts/user-story-prompt-template.md` in the `https://github.com/deanpeters/product-manager-prompts` repo。

## 模板

```markdown
### 用户故事 [ID]：

- **摘要：** [简要、令人难忘的标题，专注于用户价值]

#### 用例：
- **作为** [用户名称（如果有）、否则人物角色、否则角色]
- **我想要** [用户为实现成果而采取的动作]
- **以便** [用户的期望成果]

#### 验收标准：
- **场景：** [简要、人工可读的描述价值的场景]
- **假设：** [初始上下文或前提条件]
- **而且假设：** [额外上下文或前提条件]
- **而且假设：** [根据需要添加额外上下文]
- **而且假设：** [UI 聚焦的上下文确保'当'可以发生]
- **而且假设：** [成果聚焦的上下文确保'则'被交付]
- **当：** [触发动作的事件]
- **则：** [与'以便'对齐的期望成果]
```

## 注意事项

- 只使用一个**当**和一个**则**。多个当/则对通常意味着故事应该被拆分。
- 如果你需要多个成果，使用 `skills/user-story-splitting/SKILL.md` 拆分故事。
