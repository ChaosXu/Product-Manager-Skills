# PoL 探针模板

使用此模板记录生命证明（Proof of Life，PoL）探针。

## 模板
```markdown
# PoL 探针：[描述性名称]

## 假设
[你认为是真的的一句话陈述]
示例："如果我们把入职表单减少到3个字段，完成率将超过80%。"

## 要消除的风险
[你正在解决的特定风险或未知是什么？]
示例："我们不知道用户是否会因表单长度而放弃注册。"

## 原型类型
[选择5种风味之一]
- [ ] 可行性检查
- [ ] 任务聚焦测试
- [ ] 叙事原型
- [ ] 合成数据模拟
- [ ] Vibe-Coded PoL 探针

## 目标用户/受众
[谁将与这个探针互动？]
示例："来自我们早期访问候补名单的10个用户，非技术 SMB 所有者。"

## 成功标准（严厉真相）
[你在寻求什么真相？什么会证明你错了？]
- **通过：** 8+用户在2分钟内完成注册
- **失败：** <6个用户完成，或平均时间超过5分钟
- **学习：** 识别特定的流失字段

## 工具/技术栈
[你将用什么来构建这个？]
示例："ChatGPT Canvas 用于表单 UI，Airtable 用于数据捕获，Loom 用于会后访谈。"

## 时间线
- **构建：** 2天
- **测试：** 1天（10个用户会话）
- **分析：** 1天
- **处置：** 第5天（删除所有代码，保留学习文档）

## 处置计划
[你将如何以及何时删除这个？]
示例："用户会话完成后，存档录像，删除 Frankensoft 代码，在 Notion 中记录学习。"

## 负责人
[谁对运行和处置这个探针负责？]

## 状态
- [ ] 假设已定义
- [ ] 探针已构建
- [ ] 用户已招募
- [ ] 测试完成
- [ ] 学习已记录
- [ ] 探针已处置
```
