# 问题陈述模板

使用此模板从角色的角度框定用户问题，捕获背景和约束，并生成单句问题陈述。

## 出处
改编自 `https://github.com/deanpeters/product-manager-prompts` repo 中的 `prompts/framing-the-problem-statement.md`。

## 模板
```markdown
## 问题框架叙事

**I am:** [描述关键角色，突出3-4个关键特征]
- [关键痛点或特征1]
- [关键痛点或特征2]
- [关键痛点或特征3]

**Trying to:**
- [列出角色最关心的期望结果的单一句子]

**But:**
- [描述阻止成果的障碍]
- [成果障碍1]
- [成果障碍2]
- [成果障碍3]

**Because:**
- [同理心地描述根本原因]

**Which makes me feel:**
- [从角色的角度描述情感]

## 背景与约束
- [地理、技术、时间或人口统计因素]

## 最终问题陈述
- [单一、简洁、有同理心的总结陈述]
```
