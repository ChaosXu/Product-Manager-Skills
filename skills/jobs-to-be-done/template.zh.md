# 工作待完成（Jobs-to-be-Done）模板

使用此模板以结构化方式捕获客户工作、痛点和收益。

## 来源

改编自 `https://github.com/deanpeters/product-manager-prompts` repo 中的 `prompts/jobs-to-be-done.md`。

## 模板
```markdown
## 工作待完成

### 1. 客户工作

#### 功能工作：
- [功能任务 1]
- [功能任务 2]
- [功能任务 3]

#### 社会工作：
- [客户希望被看待的方式 1]
- [客户希望被看待的方式 2]
- [客户希望被看待的方式 3]

#### 情感工作：
- [寻求或避免的情感状态 1]
- [寻求或避免的情感状态 2]
- [寻求或避免的情感状态 3]

### 2. 痛点

#### 挑战：
- [障碍 1]
- [障碍 2]
- [障碍 3]

#### 成本性：
- [时间、金钱或精力的成本 1]
- [时间、金钱或精力的成本 2]

#### 常见错误：
- [频繁错误 1]
- [频繁错误 2]

#### 未解决的问题：
- [当前解决方案未解决的问题 1]
- [当前解决方案未解决的问题 2]

### 3. 收益

#### 期望：
- [什么可以超出期望 1]
- [什么可以超出期望 2]

#### 节省：
- [时间/金钱/精力节省 1]
- [时间/金钱/精力节省 2]

#### 采用因素：
- [增加采用可能性的因素 1]
- [增加采用可能性的因素 2]

#### 生活改善：
- [生活如何改善 1]
- [生活如何改善 2]
```
