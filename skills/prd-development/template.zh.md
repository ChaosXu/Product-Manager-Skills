# PRD 模板

使用此模板来生成结构化的产品需求文档。

## 模板

```markdown
# [特性/产品名称] PRD

## 1. 执行摘要
- 一段概述（问题 + 解决方案 + 影响）

## 2. 问题陈述
- 谁有这个问题？
- 问题是什么？
- 为什么痛苦？
- 证据（客户引述、数据、研究）

## 3. 目标用户与人物角色
- 主要人物角色
- 次要人物角色
- 待完成工作

## 4. 战略背景
- 业务目标（OKR）
- 市场机会（TAM/SAM/SOM）
- 竞争格局
- 为什么是现在？

## 5. 解决方案概述
- 高级描述
- 用户流程或线框图
- 关键特性

## 6. 成功指标
- 主要指标（我们优化的对象）
- 次要指标
- 目标（当前 → 目标）

## 7. 用户故事与需求
- Epic 假设
- 带验收标准的用户故事
- 边缘情况、约束

## 8. 范围外
- 我们不构建什么（以及为什么）

## 9. 依赖关系与风险
- 技术依赖关系
- 外部依赖关系（集成、合作伙伴）
- 风险和缓解措施

## 10. 开放问题
- 未解决的决策
- 需要发现的领域
```
