## 效率比率

### 40 法则
```
收入增长率（同比）：__________%
利润率 %：__________%

40 法则 = 增长率 + 利润率 = __________
```

**基准：**
- [ ] >40（增长和效率的健康平衡）
- [ ] 25-40（可接受）
- [ ] <25（令人担忧——烧钱而增长不足）

### Magic Number
```
本季度收入：$__________
上季度收入：$__________
收入增量 = $__________

上季度市场营销支出：$__________

Magic Number =（收入增量 × 4）/ 上季度市场营销支出
Magic Number = __________
```

**基准：**
- [ ] >0.75（高效——可以自信扩展市场营销）
- [ ] 0.5-0.75（可接受——扩展前先优化）
- [ ] <0.5（低效——增加支出前先修复 GTM）

## 基准与质量检查

### 单位经济学
- [ ] 毛利率 >70%（SaaS 应该是高利润率）
- [ ] LTV:CAC >3:1（可持续增长的最低标准）
- [ ] 回本周期 <12 个月（现金效率高）
- [ ] 边际贡献 >60%（所有可变成本后）
- [ ] LTV 使用毛利率计算（而不仅是收入）

### 资本效率
- [ ] 跑道 >12 个月（健康缓冲）
- [ ] 净烧钱随时间递减（盈利路径）
- [ ] OpEx 增速慢于收入（正向运营杠杆）
- [ ] 管理费用 <15% 收入（保持低 overhead）

### 效率比率
- [ ] 40 法则 >40（健康平衡）
- [ ] Magic Number >0.75（高效 GTM）
- [ ] 收入增长率 > OpEx 增长率（运营杠杆）

## 红旗

检查是否有以下情况：

- [ ] LTV:CAC <1.5:1（赔钱买收入）
- [ ] 回本周期 >24 个月（现金陷阱）
- [ ] 跑道 <6 个月（生存危机）
- [ ] 40 法则 <25（烧钱而没有增长）
- [ ] Magic Number <0.5（GTM 引擎故障）
- [ ] OpEx 增速快于收入（负杠杆）
- [ ] 毛利率 <60%（利润率问题）
- [ ] CAC 增加而 LTV 持平/下降（单位经济学恶化）
- [ ] LTV:CAC 很好但回本很差（健康幻觉）
