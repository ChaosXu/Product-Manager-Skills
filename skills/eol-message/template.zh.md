# EOL 消息模板

使用此模板制作具有同理心和清晰过渡指导的停产公告。

## 来源

改编自 `https://github.com/deanpeters/product-manager-prompts` repo 中的 `prompts/eol-for-a-product-message.md`。

## 模板
```markdown
## 生命周期终止公告：[产品名称]

### 产品过渡叙述

**我们是：** [公司与产品的关系]
- [对客户的承诺]
- [产品演进]
- [未来愿景]

**公告：**
- [清晰的 EOL 声明和替代品]

**因为：**
- [原因 1：以客户利益为中心]
- [原因 2]
- [原因 3]

**这意味着对你：**
- [客户影响和利益]

### 当前产品背景

**我们的产品** [名称]
- **是** [简要描述]
- **已经服务** [目标客户] [时间段]
- **通过提供** [主要利益]

### 客户影响

**我们理解这可能通过以下方式影响你：**
- [影响 1]
- [影响 2]
- [影响 3]

### 过渡方案

**对于** [目标客户]
- **目前使用** [旧产品]
- [替代产品]
- **是一种** [类别]
- **能够** [关注连续性和改进的利益]

### 差异化和连续性

- **像** [旧产品]
- [替代产品]
- **提供** [关键利益的连续性]
- **同时也提供** [新利益]

### 支持和后续步骤

**为确保顺利过渡，我们将：**
- [支持措施 1]
- [支持措施 2]
- [支持措施 3]

### 时间线
- [关键日期 1 + 里程碑]
- [关键日期 2 + 里程碑]
- [关键日期 3 + 里程碑]

### 行动号召
- [后续步骤]
- [联系信息]
```
