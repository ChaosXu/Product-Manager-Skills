# 示例：健康的 SaaS 指标

**公司：** ProjectHub（中端市场项目管理 SaaS）
**阶段：** 增长阶段，B 轮融资后
**客户群：** 200 个账户，20,000 个用户
**时期：** 月度快照

---

## 收入指标

### MRR/ARR
```
期初 MRR：$2,000,000
+ 新 MRR：$100,000（10 个新账户）
+ 扩展 MRR：$80,000（追加销售 + 使用增长）
- 流失 MRR：$30,000（5 个账户流失）
- 收缩 MRR：$10,000（3 个账户降级）
期末 MRR：$2,140,000

MRR 增长率：7% 环比
ARR：$25.7M
```

### ARPA/ARPU
```
ARPA = $2,140,000 / 200 账户 = $10,700/月
ARPU = $2,140,000 / 20,000 用户 = $107/月
每账户平均坐席 = 100 用户
```

### 收入组成部分
```
新 MRR：$100K（占总数 5%）
扩展 MRR：$80K（占总数 4%）
流失 MRR：$30K（占总数 1.5%）
收缩 MRR：$10K（占总数 0.5%）
```

---

## 留存与扩展指标

### 流失率
```
Logo 流失：5 / 200 = 2.5%/月（~26%/年）
收入流失：$30K / $2M = 1.5%/月（~17%/年）
```

**分析：** 收入流失 < Logo 流失 = 失去较小的客户，这是健康的。

### NRR
```
期初 ARR：$24M
扩展：$960K（年度）
流失：$360K（年度）
收缩：$120K（年度）
期末 ARR：$24.48M

NRR = $24.48M / $24M = 102%
```

### Quick Ratio
```
收益 = $100K + $80K = $180K
损失 = $30K + $10K = $40K
Quick Ratio = $180K / $40K = 4.5
```

---

## 分析

### ✅ 优势

**强劲增长：**
- 7% 环比 MRR 增长
- 健康组合：5% 新增 + 4% 扩展

**优秀留存：**
- 2.5% Logo 流失（低于 5% 阈值）
- 1.5% 收入流失（优于 Logo）
- 102% NRR（无需新 logo 也能增长）

**高效扩展：**
- $80K 扩展 MRR（占基础的 4%）
- 扩展驱动的 NRR
- 每账户平均扩展：$400/月

**可持续增长：**
- Quick Ratio 4.5（收益远远超过损失）
- 收入流失下降（六个月前是 2%）
- 新队列比旧队列留存更好

### 📊 机会

**扩展空间：**
- NRR 在 102% 是好的，但有增长到 110-120% 的空间
- 只有 40% 的客户扩展过（可以推到 60%）
- 交叉销售机会：30% 的客户没有使用集成附加组件

**ARPU 优化：**
- $107/用户对中端市场来说是不错的，但企业细分显示 $200/用户的潜力
- 可以引入高级层级以获取高级功能

**降低流失：**
- 2.5% Logo 流失是可接受的但不是优秀的
- 分析显示 70% 的流失发生在前 90 天（入门问题）
- 修复：改进入门，目标是 <2% Logo 流失

---

## 建议行动

1. **积极扩展获客** — 单位经济学强劲（见 `saas-economics-efficiency-metrics` 了解 CAC/LTV）
2. **改进入门** — 将前 90 天早期流失从 5% 降低到 3%
3. **扩展交叉销售** — 向 30% 没有使用它的客户群推动集成附加组件（潜在 +$30K MRR）
4. **测试高级层级** — 20 个企业客户显示愿意为高级功能支付 2 倍费用
5. **监控队列留存** — 继续追踪新队列比旧队列留存更好
